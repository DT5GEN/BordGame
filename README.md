# Осколки Долины — скачать игру

**[⬇ Скачать OskolkiDoliny_v0.5_Windows.zip](https://github.com/DT5GEN/BordGame/raw/download/OskolkiDoliny_v0.5_Windows.zip)** (≈ 92 МБ)

1. Скачай архив и распакуй в любую папку.
2. Запусти `OskolkiDoliny.exe`.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».

Ничего устанавливать не нужно. Нужен Windows 64-бит.

## Что нового в 0.5
- Игра по сети: кнопка «По сети» в меню, комната по коду из 4 букв, можно играть с ПК и с телефона одновременно.
- Холмы: подъём на этаж +1 шаг, на высоких холмах обзор больше.

## Что было в 0.3
- 10 зверей-призывов, способности героев, бонусные карты, редактор карт, кубик партии на всех.
