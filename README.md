# Осколки Долины — скачать игру

**[⬇ Скачать OskolkiDoliny_v0.4_Windows.zip](https://github.com/DT5GEN/BordGame/raw/download/OskolkiDoliny_v0.4_Windows.zip)** (≈ 90 МБ)

1. Скачай архив и распакуй в любую папку.
2. Запусти `OskolkiDoliny.exe`.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».

Ничего устанавливать не нужно. Нужен Windows 64-бит.

## Что нового в 0.3
- 10 зверей-призывов автора игры.
- Способность героя на выбор (8 штук).
- Бонусные карты на первом ходу: открой 2 из 5.
- Каждый раз разная карта (1–3 реки, разное число мостов) и код карты.
- Редактор карт в меню.
- Кубик партии выбирается в меню: один на всех и до конца игры.
