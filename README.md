# Осколки Долины — прототип

Пошаговая 3D-ходилка для 1–6 игроков на одном телефоне или компьютере.
Сделана на **Godot 4.7** по идее и правилам юного геймдизайнера (его карты ловушек и зверей — в `data/cards.json`).

## Как запустить

1. Скачайте **Godot 4.7** (обычная версия, не .NET): https://godotengine.org/download
   Это один файл, устанавливать не нужно.
2. Запустите Godot → **Import** → выберите файл `project.godot` из этой папки.
3. Нажмите **F5** (или ▶ справа вверху). Первый запуск чуть дольше: Godot импортирует шрифты.

## Что уже есть

- Меню: 1–6 игроков, имена, 10 героев-подростков (свои персонажи), питомец, размер карты.
- Генерируемая долина: две реки с мостами, леса, холмы, ущелье перед финишем, Святилище на юге.
- Кубики D6–D20 с выровненными шансами (в среднем 5–6 шагов, разный риск).
- Цена шага по местности: лес и холм — 2.
- Туман войны: соперников, зверей и осколки видно только рядом (равнина 3, холм 4, лес 2, ночью −1).
- Передача телефона между ходами с отчётом «Пока тебя не было».
- 30 ловушек сына: скрытая установка, срабатывание, хозяин узнаёт об улове.
- Осколки (больше, чем игроков): на холмах, в сундуках, у Каменных стражей. Нужно 3, чтобы войти в Святилище.
- Звери в лесах, сундуки с добычей, камни «?» со случайными событиями, костры-чекпоинты.
- Время идёт по раундам: утро → день → вечер → ночь, дождь и ветер; ночью с севера ползёт Тьма.
- Схватки между игроками: победитель забирает осколок или карту.
- Победитель следующей партии получает питомца (лисёнок, +1 к обзору).
- Свиток с правилами при свете свечи (5 страниц).

## Как менять баланс

Всё в `data/cards.json`: урон и эффекты ловушек, их цены, грани кубиков, сила зверей, предметы.
Позже здесь будет внутриигровой редактор с ограничениями, чтобы ни одна карта не стала «божественной».

## Для разработчиков

- `scripts/game/game.gd` — логика партии; `scripts/world/` — карта и модели; `scripts/ui/` — интерфейс и свиток.
